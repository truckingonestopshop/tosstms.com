# Supabase email templates (TOSS)

Built by `node supabase/templates/build.mjs`. In Supabase → Authentication → Emails → Templates, paste each subject and the matching `.html` file.

| Template file | Subject |
|---|---|
| invite | You're invited to TOSS TMS |
| recovery | Reset your TOSS TMS password |
| magic_link | Your TOSS TMS sign-in link |
| email_change | Confirm your new TOSS TMS email |
| confirmation | Confirm your TOSS TMS email |
| reauthentication | Your TOSS TMS verification code |

Template names: invite = "Invite user", recovery = "Reset password", magic_link = "Magic link", email_change = "Change email address", confirmation = "Confirm signup", reauthentication = "Reauthentication".
